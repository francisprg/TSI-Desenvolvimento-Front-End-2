# Exercicio 01

# TodoList com UseEffect

Descrição da atividade
Desenvolver um aplicativo ToDoList (Lista de Tarefas) utilizando os hooks useState e useEffect, com os seguintes requisitos:
- As tarefas deverão ser armazenadas no localStorage.
- Cada tarefa deverá ter uma lista de passos ou etapas a serem cumpridas.
- Deverá ser possível criar e remover tarefas, assim como os passos de cada tarefa
